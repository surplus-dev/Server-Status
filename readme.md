# Server Status

클라이언트가 3분마다 CPU, RAM, GPU 및 디스크 상태를 서버로 전송하고, 서버의 `/` 페이지에서 확인할 수 있습니다.

## 디스크 용량

- 클라이언트는 마운트된 물리 디스크의 파일시스템별 전체 용량, 사용 용량, 남은 용량과 사용률을 수집합니다. 컨테이너 등에서 물리 디스크 목록에 루트 파일시스템이 없으면 루트도 포함합니다. Snap 패키지의 squashfs 이미지처럼 저장 공간으로 사용할 수 없는 항목은 제외합니다.
- 서버 화면에는 마운트 경로와 장치 이름, 남은 용량, 전체 용량, 사용 용량 및 사용률이 표시됩니다. 용량 단위는 KiB, MiB, GiB 등 1024 기준입니다.
- 남은 용량은 클라이언트 실행 계정이 사용할 수 있는 공간입니다. 파일시스템의 예약 공간 때문에 전체 용량에서 사용 용량을 뺀 값과 다를 수 있습니다.
- 디스크를 읽지 못하면 해당 디스크는 `N/A`로 표시하고 다른 상태 정보는 계속 전송합니다. 디스크 정보가 없는 기존 클라이언트의 데이터도 `DISK: N/A`로 표시합니다.
- 서버와 클라이언트를 새 빌드로 재시작하면 다음 메트릭 수신부터 디스크 정보가 표시됩니다. 서버 프로세스가 실행되는 장비도 모니터링하려면 그 장비에서 클라이언트를 실행합니다.

디스크 정보는 기존 `/api/metrics` 요청의 `disks` 배열로 전달되고 기존 메트릭과 함께 저장됩니다.

```json
{
  "disks": [
    {
      "mountpoint": "/",
      "device": "/dev/sda1",
      "fstype": "ext4",
      "total_bytes": 107374182400,
      "used_bytes": 64424509440,
      "free_bytes": 42949672960,
      "used_percent": 60
    }
  ]
}
```
